# Multi‑Platform Observability Demo

A complete, vendor‑agnostic observability showcase integrating:

- OpenTelemetry Demo  
- Cribl Stream  
- Grafana (Loki, Tempo, Mimir)  
- Elastic Observability  
- AWS Lambda (custom telemetry processor)  
- Dynatrace (external OTLP ingestion only)

This project demonstrates senior‑level SRE, observability, and platform engineering skills by routing telemetry across multiple backends using OpenTelemetry + Cribl.

---

## 🎯 Purpose

This environment is designed to:

- Demonstrate cross‑platform observability  
- Validate multi‑backend ingestion pipelines  
- Practice trace analysis, log correlation, and metrics dashboards  
- Provide a reusable demo for interviews and workshops  
- Showcase real‑world experience with OTel, Cribl, Grafana, Elastic, Dynatrace, and AWS  

---

## 🧩 Features

### ✔ OpenTelemetry Demo  
Generates real microservice telemetry.

### ✔ Cribl Stream Routing  
Routes telemetry to:

- Elastic  
- Grafana Loki  
- Grafana Tempo  
- Grafana Mimir  
- AWS Lambda  
- Dynatrace OTLP (external only)

### ✔ Grafana Stack  
Logs, traces, metrics, dashboards.

### ✔ Elastic Observability  
APM, logs, traces, dashboards.

### ✔ AWS Lambda  
Custom telemetry processor.

### ✔ Synthetic Data Generator  
Random traces, logs, metrics.
